## PLAN_BLOCKED structure

```text
PLAN_BLOCKED

Condition: <specific blocker>
Evidence: <source references>
Affected frozen field or Build requirement: ...
Resolution owner: Scout | human authority | repository owner | Build Agent contract owner
Resolution needed: ...
```

Do not add speculative implementation increments after a blocking condition that prevents safe planning.
